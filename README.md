# Marketing Intelligence Bot

Бот собирает материалы о маркетинге, брендах, потребителях и B2B/GTM, оценивает их через GigaChat и отправляет подходящие карточки в Telegram. В карточках могут быть изображения и кнопки 👍/👎.

## Как проходит выпуск

1. `config/sources.json` задаёт список источников и тематические правила.
2. `run.py` собирает материалы, убирает повторы, оценивает их и отправляет карточки.
3. `feedback.py` сохраняет реакции читателя.
4. `subscriber_bot.py` получает нажатия кнопок и записывает оценки.
5. `daily_run.ps1` запускает ежедневный выпуск; `install_daily_task.ps1` настраивает расписание Windows.

## Где что лежит

- `config/` — настройки источников.
- `run.py` — сбор, отбор, карточки и отправка.
- `feedback.py`, `subscriber_bot.py` — кнопки и сбор реакций.
- `tests/` — проверки отдельных частей проекта.
- `README.txt`, `INSTALL.txt`, `TOOLS.txt` — дополнительные заметки и инструкции.
- `.env.example` — перечень настроек без секретных значений.
- `.env`, `state/`, `outputs/` — локальные секреты, история и журналы; Git их не загружает.

## Важно про GitLab

GitLab хранит исходный код и его версии. Он сам по себе не запускает бота. Сейчас бот запускается на компьютере; ежедневное расписание и сбор реакций остаются на нём.

Репозиторий следует оставить приватным. В нём нет реального `.env`, истории пользователя, логов, резервных архивов и файлов состояния. Чтобы настроить копию проекта на другом компьютере, скопируйте `.env.example` в `.env` и внесите значения ключей только локально.

## Основные файлы для повседневной работы

- Добавить или отключить источник: `config/sources.json`.
- Изменить правила отбора и формат карточек: `run.py`.
- Изменить обработку лайков и дизлайков: `feedback.py`, `subscriber_bot.py`.
- Проверить изменения без отправки сообщений: запустить `Dry-Run.cmd`.
- Отправить выпуск вручную: `Run-Manual-Send.cmd`.
